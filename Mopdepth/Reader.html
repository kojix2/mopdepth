    class Mopdepth::Reader

    • Mopdepth::Reader
    • Reference
    • Object

    Overview

    An indexed BAM/CRAM coverage reader.

    A Reader owns its HTS handle and is intended for serial use. Create one Reader per concurrent worker. Call #close, or use the block form of Reader.open, to release the native handle deterministically.
